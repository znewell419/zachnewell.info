# zachnewell.info

Personal portfolio website for Zachary Newell.

🌐 Live Site: https://zachnewell.info

## Overview

This repository contains the source code for my personal portfolio website. The site showcases my professional background, technical projects, resume, and experience in IT and systems administration.

The website is built as a lightweight static site and is self-hosted on my own Linux server.

## Features

- Responsive personal portfolio website
- About page
- Projects showcase
- Resume download
- Contact page
- Search engine optimization files (`robots.txt` and `sitemap.xml`)
- Self-hosted deployment

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Caddy Web Server
- Arch Linux
- Cloudflare DNS

## Deployment

The website is hosted on a self-managed Arch Linux server.

Deployment workflow:

1. Website changes are committed to GitHub
2. Changes are pulled onto the server
3. Caddy serves the static website files
